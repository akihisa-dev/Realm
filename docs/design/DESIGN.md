# Realmデザイン正本

## 現行のレイヤー操作

固定されたterrain/region/objectタブはありません。右パネルは階層treeで、leafを選択するとそのleafのtyped contentと描画種類設定を表示します。group追加、leaf追加、rename、上下移動、indent/outdent、visible/lockedを操作でき、地物を持つnodeや子を持つnodeは削除できません。

左railは地形・領域では「グリッド」「範囲」「消す」「掴む」を独立したアイコンボタンで表示し、オブジェクトでは種類依存の「描く」「消す」「掴む」を表示します。領域色だけはグリッドまたは範囲を選択したときの候補flyoutで選び、描き方の二択をflyoutへまとめません。シェイピングは選択regionの右パネル操作に置きます。地図移動とzoom gestureはrail項目ではありません。

## 目的

Realmの編集画面は静かに保ち、地図を画面の主役にします。
初期画面はmacOSのユーティリティであり、ダッシュボードやファンタジー風の演出画面ではありません。
表示のスタイルは、階層treeとtyped contentから導出するrendererです。

## 初期状態

- Realmはエディタを直接開き、固定128×73の六角形編集グリッドを、相対ズーム1の中央寄せ4:3キャンバスフレームへ表示する。開いていた世界があれば復元し、なければライブラリの最初の世界を開き、ライブラリが空なら`無題の世界`を作成する
- 右パネルは階層treeのレイヤー管理である。leafがactive editing layerを選び、選択したleafだけが主ポインターによる編集を受け付ける。typed contentはすべて表示する
- 左ツールレールには、地形・領域では「グリッド」「範囲」「消す」「掴む」を独立して表示し、オブジェクトでは種類依存の「描く」「消す」「掴む」を表示する。最下部に「新規作成」を置き、描く内容、領域操作、オブジェクトの種類と一覧操作は右のレイヤー管理で扱う
- グリッドと範囲は地形・領域で共通の描き方であり、選択中の末端レイヤーと描く内容が保存結果を決める。オブジェクトは種類ごとの点またはポリゴン配置を使い、領域を地形へ合わせる操作は右パネルから行う
- プレビューはrendererだけで完結する読み取り専用状態である。レイヤーの切り替えと編集操作を無効にし、地図移動と拡大縮小は残す。Escape、pointercancel、blur、キャプチャ喪失、レイヤー切り替えでは未完了のジェスチャーをキャンセルする

## ビジュアルシステム

- 画面の枠には、純白と冷たいニュートラルグレーを使う。既定の地図キャンバスも純白とし、編集時の保存済み地形は塗りなしの正確な輪郭で表示する。読み取り専用プレビューとラスター出力では、地形の淡い塗り、海岸の外光、領域の複層境界をrendererだけで重ね、地図としての奥行きを出す
- 文字はチャコールにし、選択色には抑制した濃い青緑を使う。macOSのシステムフォントスタックと、明示的でコンパクトな操作用文字サイズを使う
- 入れ子のカードや浮遊パネルより、レール、区切り、タブ、一覧、画面いっぱいの地図キャンバスを優先する
- 境界線は細く低コントラストにする。影はキャンバス上に置く必要がある操作部品に限る。キーボードフォーカスは見える状態を保つ
- 地形と領域の遷移、オブジェクト配置のフィードバック、プレビューの平滑化と複層スタイルはrendererだけの効果である。保存データやundo履歴を変更せず、reduce motionでは直ちに解決する

## レイアウト契約

macOSのnative title barには、アプリ名`Realm`とversionを横並びで表示します。rendererの編集ヘッダーには、共通の`太さ`範囲と、右にアイコンだけのプレビュー、履歴、レイヤーパネル操作を置きます。
主役のOpenLayersキャンバスは、独立した描画操作、消去、掴む操作と下部の新規作成アクションを置く左ツールレールと、右レイヤー管理の間に置きます。
下部のズームバー、macOSのtraffic lightの2組目、開閉する補助ツールパネルは表示しません。

選択したleafの内容は右のtree下に表示します。
右パネルは閉じられますが、閉じても`selectedLayerId`は変わりません。
再び開くと同じレイヤーを表示します。
treeと内容パネルはプレビュー中と変更のコミット中に無効にします。

地図は、地図移動中に主ボタンをドラッグすると移動します。
中ボタンまたは右ボタンのドラッグは、どのツールでも選択レイヤーを変えずに地図を移動します。
Spaceを押しながら主ボタンをドラッグしても同じ一時的なナビゲーションになります。
地図上の右クリックメニューは抑止します。
ホイール回転でキャンバスをズームします。
視点の移動は固定された編集範囲内に制限します。

カーソルはactive operationを表します。
グリッド描画または範囲描画ではcrosshair、オブジェクト種類ではオブジェクト配置用カーソル、ナビゲーションと形状移動ではgrab、削除では消しゴム用カーソルを使います。
地図をドラッグしている間は、OpenLayersの`grab`と`grabbing`の表示を最優先します。

## 許可する画面文言

左ツールレールでは地形・領域の`グリッド`と`範囲`を別々に表示し、その後ろに`消す`、`掴む`を置きます。オブジェクトでは種類依存の`描く`、`消す`、`掴む`を表示し、最下部には常に`新規作成`を置きます。右パネルで描く内容を選び、選択した領域を地形へ合わせます。新規作成は現在の世界を残したまま空の新しい世界を開きます。
領域の色はグリッドまたは範囲の選択時に候補flyoutで選び、消去は選択したactive layerだけを直接実行します。オブジェクトの種類は右パネルで選びます。
ヘッダーの太さ操作はグリッド描画とセル消去で共有し、範囲描画では囲い込みの線を使い、オブジェクト配置では使いません。

右パネルのアクセシブル名は`レイヤー管理`とします。
地形タブは現在の地形形状を表示し、領域タブは論理的な領域と分離した部分を一覧し、オブジェクトタブは種類選択、ラベル入力、配置、選択、移動、削除を提供します。
領域は常に領域と呼び、オブジェクトとは呼びません。

## rendererの境界

Reactは一時的な画面状態を所有します。
対象はactive layer、active operation、オブジェクトの下書き、領域の色、viewport、共有描画範囲、セル選択、選択中のオブジェクトと領域、レイヤーパネル状態、プレビュー状態です。
OpenLayersのオブジェクト、導出した六角形ポリゴン、テーマ定義はmap adapterの背後に置き、保存処理にはしません。

renderer registryは、地形、領域、オブジェクトに別々のsourceとlayerを保持します。
描画順は次のとおりです。

```text
terrain → region → object
```

地形と領域の編集には、保存済みの正確なグリッド吸着Polygonジオメトリを使います。
プレビューでは輪郭を滑らかにした形状を導出できますが、正規ジオメトリを置き換えません。
オブジェクトのstyleは種類で決まり、`label`、`properties`、`locked`、`asset_id`、`z_index`を読み取ります。
オブジェクトの重なりは意図的に許可します。
セルポリゴンとセルIDは一時的なペイント、消去、ヒットテストだけを支えます。

active-layer gateはReactだけでなくadapterでも強制します。
選択、主ポインターによる描画、移動、消去はactive layerだけに絞ります。
レイヤーを切り替えるとadapterのポインター操作と制御された選択を消去してから、次のレイヤーのモードを設定します。
パンとズームはこのゲートの対象外で共通です。

## アプリケーションアイコンの素材

透明PNGのmasterを、Electron Forgeが使う同梱アプリアイコンの正本にします。
白い角丸タイルと輪郭マークは不透明のままにし、外側の四隅はすべて透明にします。
その他のPNGサイズと`icon.icns`はmasterから生成します。
パッケージ検査では、アプリを起動せずに同梱アイコンとmetadataを確認します。
